# Кейс: приём заявок через MAX и n8n

**Автор:** Пулат Сафаров  
**Область:** бизнес-автоматизация  
**Публичная версия:** обезличенный шаблон, не подключённый к рабочим credential и данным.

## Задача

Перевести первичный диалог с клиентом в понятный сценарий: выбор услуги, выбор способа связи, передача контакта и регистрация заявки. Менеджеру должно приходить уведомление, клиенту — подтверждение.

## Решение

Собран детерминированный workflow в n8n. Code-ноды нормализуют входящие события MAX, хранят этап разговора и формируют следующее сообщение. Кнопки MAX управляют выбором услуги и маршрутом связи. Данные сессий и заявок разделены по таблицам n8n Data Tables.

Отдельная модель ИИ не используется: для короткого фиксированного сценария это упрощает поддержку и не добавляет расходы на генерацию.

## Обработка сценария

1. Входящее событие проходит нормализацию и проверку необходимых полей.
2. Workflow загружает состояние диалога и отсекает повторное событие.
3. Клиент выбирает услугу и способ связи.
4. При передаче контакта или выборе самостоятельной связи создаётся заявка.
5. Заявка сохраняется, менеджеру уходит уведомление, клиенту — ответ.
6. После завершения можно начать новый диалог.

## Проверяемые результаты

Локальные изолированные тесты JavaScript-логики прошли: два чистых прогона, 800 синтетических сценариев и 4 414 нормализованных событий суммарно. Покрыты две ветки связи, проверка контакта MAX, повторы событий и новая заявка.

Это не нагрузочное испытание активного n8n, MAX API или Data Tables. Публичный шаблон намеренно выключен; никаких реальных сообщений и записей из этого репозитория не создавалось. Коммерческие показатели и эффект для бизнеса не заявляются.

## Обезличивание

Перед публикацией удалены рабочие credential и webhook ID, заменены таблицы, телефонные номера, MAX ID и имя менеджера; сгенерированы новые ID узлов. Автор кейса указан по просьбе владельца репозитория.

## Использование шаблона

Перед импортом настройте отдельные тестовые credential, таблицы, контакты и уникальный webhook path. Не включайте импортированный workflow, пока не проверили все `REPLACE_WITH_*` значения на тестовом боте.
