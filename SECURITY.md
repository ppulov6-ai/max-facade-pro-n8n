# Безопасность

- Не публикуйте токены, credential, реальные MAX ID, номера телефонов и клиентские данные.
- Храните секреты только в credential store n8n.
- Для проверки используйте отдельного тестового бота и тестовые таблицы.
- Публичный workflow выключен; перед включением замените все `REPLACE_WITH_*` и задайте уникальный webhook path.
- При обнаружении раскрытого секрета немедленно отзовите его у провайдера, затем сообщите владельцу репозитория приватно. Не размещайте секрет в issue.
